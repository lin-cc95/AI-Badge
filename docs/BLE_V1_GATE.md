# BLE V1 冻结门槛

真实 `BleDeviceAdapter` 开发前，硬件方必须签字确认以下内容：

1. 广播名称、Service UUID、Characteristic UUID、Manufacturer Data 和扫码字段。
2. 设备身份、挑战应答、会话密钥、换绑、解绑、恢复出厂和防重放策略。
3. 命令帧头、版本、操作码、序号、载荷长度、校验、ACK/NACK 和错误码。
4. PNG/WebP 或设备原生资源的尺寸、圆形遮罩、色深、压缩、帧率和容量。
5. MTU、分片大小、发送窗口、超时、重试、断点查询和最终 `SAVED_AND_LOADED` 回执。
6. 点击、双击、长按、摇晃、抬起事件以及固件去抖/节流参数。
7. OTA 包签名、兼容范围、最低电量、升级状态、回滚、恢复模式和版本确认。
8. App 被杀、手机切后台、设备休眠、跨手机换机和时钟同步行为。

冻结前只允许实现 `VirtualDeviceAdapter` 和协议测试夹具；不得把临时 UUID 或模拟成功回执写进生产实现。
