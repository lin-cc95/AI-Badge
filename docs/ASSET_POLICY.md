# 资产与数据政策

仓库只接受原创、明确获授权或许可证兼容的图片、动画、字体、声音和文档。

- 参考图只能用于表达设计方向，除非得到明确授权，否则不得直接提交或复刻品牌、
  角色、图标和页面组合。
- 提交第三方资产时，必须记录来源、作者、许可证、修改情况和所需署名。
- AI 生成资产必须满足所用模型和提供商的条款，不得包含提示词中的个人数据、
  商标仿冒或未经授权的角色形象。
- 截图、诊断包和测试夹具不得包含真实用户图片、令牌、完整对话或设备标识。
- `apps/mobile/ai-badge-ios-preview.png` 是本项目界面的演示截图；应用图标仍是占位资产，
  发布商店版本前必须替换并完成权利审查。

除文件内另有说明外，本仓库原创资产和文档与代码一同按 Apache-2.0 授权。
